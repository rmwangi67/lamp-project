# LAMP Stack Deployment on AWS EC2

## Project Overview
This project demonstrates the deployment of a LAMP stack using Ubuntu, Apache, MySQL, and PHP on AWS EC2.

## Technologies
- Linux (Ubuntu 24.04)
- Apache Web Server
- MySQL 8.0
- PHP

## Website
http://51.20.67.53

## Objective
To configure a web server on AWS EC2 and prepare it to serve web pages using PHP and MySQL.
